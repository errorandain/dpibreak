# DPI-обход: теория и техники (справка проекта)

## Как устроена блокировка

В РФ фильтрация выполняется на ТСПУ (технические средства противодействия угрозам) на стороне провайдера. Основные механики против YouTube/Discord:

- **DPI по SNI**: TLS ClientHello передаётся открытым текстом; ТСПУ читает поле SNI (имя сервера) и режет/замедляет соединения к «неугодным» доменам. Основная мишень наших техник.
- **Блокировка/замедление по IP**: адреса сервиса/CDN. Десинк **не помогает** — только прокси/VPN.
- **DNS-фильтрация**: подмена/обнуление ответов. Лечится своим DoH-резолвером.
- **Замедление по протоколу**: дросслинг QUIC (UDP 443) и т.п.

## Идея десинхронизации

DPI анализирует поток, а сервер — восстанавливает его по правилам TCP/TLS. Если отправить данные так, чтобы **DPI увидел искажённый запрос, а сервер получил корректный**, фильтр пропустит соединение. Способы (реализованы в byedpi — наш движок):

| Техника | Аргумент byedpi | Что происходит |
|---|---|---|
| **Split** | `-s 0+s` | ClientHello разбивается на 2+ TCP-сегмента (например, по границе SNI). Большинство ТСПУ не собирают сегменты обратно |
| **Disorder** | `-d 3+s` | Часть запроса отправляется с TTL=1 (погибает в пути), затем остальное; после SACK ядро ретранслирует «потерянное» — порядок на сервере восстанавливается, DPI видел мусор |
| **Fake** | `-f 7 -t 8` | Перед реальным запросом отправляется поддельный ClientHello с малым TTL: DPI его разбирает, до сервера он не доходит |
| **Fake SNI** | `--fake-sni` | В фейке подставляется «безобидный» SNI (рандомизированный) |
| **tlsrec** | `-r 3+s` | ClientHello режется на две TLS-записи (заголовок записи вставляется в середину SNI) |
| **OOB** | `-o` | Байт уходит как out-of-band данные: DPI видит его в SNI, стек сервера — выносит из потока |
| **UDP fake** | `-a 3` | Фейковые UDP-пакеты для QUIC-хендшейков |
| **mod-http** | `-M h,d,r` | Трюки с заголовком Host для HTTP (`hOsT:`, `NaMe`, `Host:x\t`) |
| **Авто-режим** | `-A torst,ssl_err` | По признакам блокировки (таймаут/RST, кривой TLS-ответ) переключается на следующую группу параметров, результат кешируется по IP |

Полный справочник аргументов: [README byedpi](https://github.com/hufrea/byedpi/blob/main/README.md).

## Что невозможно без root (и чем zapret отличается)

| Техника zapret | Без root? |
|---|---|
| split / fake+TTL / disorder / tlsrec / oob / udp-fake | ✅ работает (наш случай) |
| `badsum` (порча контрольной суммы), `badseq` (подмена seq), `syndata` (данные в SYN), `ts`-fooling, `autottl` | ❌ только raw-сокеты (root) |

Этого достаточно: все актуальные Android-приложения обхода (ByeByeDPI и др.) работают в userspace.

## Практика по сервисам

### YouTube
1. Замедление по SNI → split/disorder/fake на ClientHello (наши пресеты).
2. **QUIC:** видео в браузерах/приложениях может идти по UDP 443 (HTTP/3), где TCP-трюки не действуют. Решение — блокировать/заворачивать UDP 443, чтобы клиент откатился на TCP+TLS.
3. CDN: `googlevideo.com` — основные домены раздачи видео (см. hostlist).

### Discord
Голосовые (`discord.media`) и API-домены режутся по SNI. Работают fake+split, при необходимости — `--fake-sni`. 

### Telegram
- В большинстве сетей РФ **доступен напрямую** — обход чаще не нужен.
- Если на конкретной сети фильтруется по DPI (редко) — помогает split.
- Если заблокирован **по IP** — десинк бессилен; единственный путь — прокси (MTProto/SOCKS; поддержка upstream-прокси — в roadmap).

## DNS

Обязательно: перехват DNS из TUN. ТСПУ и провайдеры могут подменять DNS-ответы (пустой ответ/чужой IP для заблокированных доменов). Решение: встроенный **DoH** (DNS-over-HTTPS, `https://dns.google/dns-query`, `https://cloudflare-dns.com/dns-query` и т.п.) с кешированием. DoT (853) может блокироваться — не полагаться.

## Подбор стратегии под провайдера

Разные операторы = разные ТСПУ. Алгоритм:
1. Выбрать пресет (общий → youtube → …).
2. Проверить: открыть youtube.com/discord.com, запустить видео/звонок.
3. Не работает — менять параметры по одному: позиция split (`0+s`, `1+s`, `2+s`), TTL фейка (`-t 4..12`), добавлять `-r 3+s`, `--fake-sni`, авто-режим `-A torst,ssl_err`.
4. Найти рабочую комбинацию → сохранить как пользовательский пресет.

В перспективе (roadmap): автоматический прогон «сайт × стратегия» с замером времени ответа — по образцу `blockcheck` из zapret и автоконфигурации DPI Tunnel.
