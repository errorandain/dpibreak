# ⚙️ Настройка Qwen Code — чтобы ИИ сам работал с проектом и GitHub

**Что изменится:** сейчас вы копируете код из веб-чата Qwen в Android Studio руками.
После настройки Qwen будет работать **прямо в папке проекта**: сам читает файлы,
сам вносит изменения (показывая вам, что меняет), сам запускает сборку и читает её
логи, сам делает коммиты. Вы — принимаете решения и проверяете результат на телефоне.

```
Было:  Qwen-чат → копируете код → Android Studio → сборка → GitHub Desktop
Станет:  Qwen Code (в терминале) → всё сам → вы нажимаете «да» и проверяете
```

Время настройки: ~20 минут. Нужен интернет, ~500 МБ свободного места.

---

## Шаг 1. Установить Node.js (5 минут)

Qwen Code работает поверх Node.js.

1. Откройте **nodejs.org** → нажмите большую зелёную кнопку **«Download Node.js (LTS)»**.
2. Запустите скачанный файл → устанавливайте, ничего не меняя (Next → Next → Install → Finish).
3. **Важно:** после установки закройте Android Studio, если она открыта (ей нужен перезапуск, чтобы увидеть новую программу).

✅ **Проверка:** нажмите Win+R → введите `cmd` → Enter → в чёрном окне наберите:
```
node -v
```
Должно ответить что-то вроде `v22.x.x`. Закройте окно.

---

## Шаг 2. Установить Git for Windows (5 минут)

Нужен, чтобы Qwen мог делать коммиты (GitHub Desktop использует свой «встроенный» git, терминальному он не виден).

1. Откройте **git-scm.com/download/win** → скачивание начнётся автоматически.
2. Установите со всеми настройками по умолчанию (просто Next до конца).
3. Представьтесь git'у — он должен знать, чьё имя ставить в коммитах. Win+R → `cmd` → две команды (логин — ваш на GitHub, почту возьмите ту, что привязана к GitHub):
```
git config --global user.name "ВашЛогин"
git config --global user.email "ваша@почта.com"
```
> 💡 Если включали в GitHub «Keep my email addresses private» — используйте адрес вида `ЛОГИН@users.noreply.github.com` (он на странице github.com/settings/emails).

✅ **Проверка:** в том же чёрном окне: `git --version` → ответит `git version 2.x`.

---

## Шаг 3. Установить Qwen Code (3 минуты)

Win+R → `cmd` → команда:

```
npm install -g @qwen-code/qwen-code
```

Подождите 1–2 минуты (текст побежит по экрану — это нормально).

✅ **Проверка:** наберите `qwen --version` → покажет номер версии.

❌ Если «npm не является внутренней или внешней командой» — Android Studio/терминал были открыты до установки Node: закройте ВСЕ окна терминалов и Android Studio, откройте заново.

---

## Шаг 4. Вход в аккаунт Qwen (3 минуты)

1. Win+R → `cmd` → наберите `qwen` → Enter.
2. Qwen покажет выбор способа входа — стрелками на клавиатуре выберите **«Login with Qwen»** (вход через ваш аккаунт Qwen, бесплатный: ~2000 запросов в день) → Enter.
3. Откроется браузер → войдите **тем же аккаунтом**, которым пользуетесь в чате Qwen → подтвердите доступ.
4. Вернитесь в чёрное окно — там появится приветствие Qwen.
5. Наберите `/quit` (или просто закройте окно) — вход запомнен.

---

## Шаг 5. Положить в проект файл AGENTS.md (2 минуты)

`AGENTS.md` — «паспорт проекта» для Qwen: правила, архитектура, запреты. Qwen Code читает его **автоматически при каждом запуске**.

1. Возьмите файл `AGENTS.md` из проекта (он в архиве `dpibreak.zip` в этом чате / в предпросмотре файлов) — либо скачайте обновлённый `dpibreak.zip` и скопируйте из него один этот файл.
2. В Android Studio: правый клик на самой верхней строке дерева проекта (**dpibreak**) → **New → File** → имя `AGENTS.md` → OK → вставьте содержимое (Ctrl+V) → Ctrl+S.
3. Файл должен лежать именно в корне: `C:\Projects\dpibreak\AGENTS.md` (рядом с `README.md`).

---

## Шаг 6. Первый запуск в проекте (2 минуты)

1. Откройте Android Studio с проектом dpibreak.
2. Внизу слева найдите вкладку **Terminal** (Терминал) и нажмите её — откроется командная строка прямо в папке проекта.
3. Наберите:
```
qwen
```
4. Появится интерактивный режим Qwen (поля ввода внизу).

✅ **Проверка, что всё работает:** напишите:
```
Опиши в трёх предложениях, что за проект и на каком мы этапе.
```
Qwen должен сам прочитать `AGENTS.md`, `README.md`, `docs/ROADMAP.md` и ответить по делу (про DPIBreak, обход DPI, этап M1/Задача 1). Если ответил осмысленно — всё настроено! 🎉

## Новый рабочий цикл (вместо старого копипаста)

Теперь каждая задача выглядит так:

| Шаг | Что делаете вы |
|---|---|
| 1 | В Qwen: **«Выполни Задачу 1 из docs/qwen/TASKS.md. Сначала покажи план»** |
| 2 | Читаете план → «ок, делай» |
| 3 | Qwen показывает изменения файлов. Каждое — с вопросом. Отвечайте **y** (да) или **n** (нет). Клавиша **a** — «да для всех в этой сессии» |
| 4 | Qwen: «запусти сборку» → соглашаетесь → он сам выполняет `gradlew assembleDebug` и сам читает вывод |
| 5 | Ошибки? → «исправь» — он правит и пересобирает сам |
| 6 | Успех (BUILD SUCCESSFUL) → **«закоммить»** → он делает коммит → **«запушь»** → заливает на GitHub (при первом push может открыться окно авторизации GitHub — разрешите) |
| 7 | Забираете `app-debug.apk` (путь подскажет Qwen), ставите на Samsung, проверяете по критериям приёмки задачи |
| 8 | Следующая задача — только после проверки текущей |

**Первый push:** если появится окно «Sign in with your browser» от Git Credential Manager — нажмите в нём кнопку входа через браузер и войдите в GitHub. Это одноразово.

## Полезные команды Qwen Code

| Команда | Что делает |
|---|---|
| `/help` | список всех команд |
| `/clear` | очистить контекст (начать «новую тему» без истории) |
| `/read путь` | явно подсунуть файл в контекст |
| `/stats` | сколько запросов потрачено (лимит ~2000/день) |
| `/quit` | выход |
| **Esc** | прервать ответ, если понесло не туда |

---

## Правила безопасности (важно!)

- **Не включайте режимы «автоматически принимать всё» (YOLO/auto-accept all).** Соглашивайтесь с каждым изменением вручную — вы должны хотя бы видеть, какие файлы меняются.
- Qwen не может ничего «сломать навсегда»: история в GitHub хранит всё. Откат: GitHub Desktop → вкладка **History** → правый клик на плохом коммите → **Revert changes in commit**.
- Если Qwen предлагает сделать что-то из раздела «Запреты» AGENTS.md (push без команды, изменение CI, коммит ключей) — отказывайтесь и напомните ему про AGENTS.md.

---

## Если что-то пошло не так

| Симптом | Решение |
|---|---|
| `npm не является командой` | Перезапустить все терминалы и Android Studio после установки Node |
| `qwen` не запускается | Переустановить: `npm install -g @qwen-code/qwen-code@latest` |
| Qwen не видит файлы проекта | Убедитесь, что запустили `qwen` в терминале Android Studio (вкладка Terminal), а не в домашней папке |
| Лимит запросов кончился | `/stats` покажет расход; лимит обновится на следующий день; либо настройте API-ключ Model Studio |
| Push просит пароль и не пускает | Это окно Git Credential Manager — войдите через браузер с аккаунтом GitHub |
| Qwen «завис» | Esc, затем переформулируйте; совсем плохо — `/quit` и запустить заново |
| Веб-чат Qwen | По-прежнему работает! Старый способ с MASTER-CONTEXT.md — запасной, задачи те же |

---

## Что стало со старыми документами?

- `docs/qwen/MASTER-CONTEXT.md` — остаётся как **запасной способ** (работа через веб-чат без Qwen Code).
- `docs/qwen/TASKS.md` — главный план задач, им пользуются оба способа.
- `AGENTS.md` — новый файл для Qwen Code, читается автоматически.
