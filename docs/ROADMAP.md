# Roadmap

Легенда: ⬜ не начато · 🔄 в работе · ✅ готово. Задачи с номерами — в [`qwen/TASKS.md`](qwen/TASKS.md).

## M0 — Каркас репозитория ✅
- ✅ Структура проекта, Gradle, CI-workflow, документация
- ✅ Скелет кода: VpnService, DesyncEngine, TunSocksBridge, пресеты, hostlists

## M1 — VPN-цикл (Задачи 1–3)
- ⬜ UI: статус сервиса, кнопка вкл/выкл реально управляет сервисом
- ⬜ Foreground-сервис с уведомлением
- ⬜ TUN поднимается (`establish()`), интернет через него ещё не идёт — норма для этапа
- ⬜ Корректная остановка, повторный запуск, отзовённое разрешение (onRevoke)

## M2 — Сквозной трафик (Задачи 4–5) 🔥 главный рубеж
- ⬜ Git submodule: byedpi; JNI-мост; локальный SOCKS5 работает
- ⬜ Git submodule: hev-socks5-tunnel; TUN → SOCKS5
- ⬜ VPN включён → все сайты открываются (пока без обхода)

## M3 — Обход (Задачи 6–7)
- ⬜ Пресеты YouTube/Discord/Telegram из `domain/Strategy.kt` реально применяются
- ⬜ Hostlists из assets передаются в движок (`-H`)
- ⬜ Блокировка/обработка UDP 443 (QUIC) — YouTube-видео стабильно
- ⬜ DoH-резолвер, DNS из TUN
- ⬜ YouTube и Discord открываются на тестовом Samsung

## M4 — Зрелость (Задачи 8–10)
- ⬜ Выбор стратегии в UI + пользовательские пресеты (сохранение)
- ⬜ Per-app исключения (банки, Госуслуги)
- ⬜ Экран логов
- ⬜ Quick Settings Tile
- ⬜ Автозапуск после загрузки + BootReceiver
- ⬜ Экономия батареи: рекомендации (whitelist от оптимизации)

## M5 — Релиз (Задачи 11–12)
- ⬜ Release-подпись, keystore в secrets
- ⬜ CI собирает подписанный APK → GitHub Releases
- ⬜ README: скриншоты, FAQ, инструкция
- ⬜ Иконка, название (переименовать при желании)
- ⬜ Публичный анонс

## M6+ — Идеи (не в MVP)
- ⬜ Свой движок десинка на Kotlin (замена byedpi, учебная ценность и полный контроль)
- ⬜ Автоподбор стратегии под провайдера (прогон «сайт × стратегия», по образцу blockcheck)
- ⬜ Профили по сетям (Wi-Fi SSID / мобильный оператор)
- ⬜ Поддержка upstream-прокси для IP-блокировок (Telegram-кейсы)
- ⬜ Root-режим (опция): nfqws из zapret через iptables NFQUEUE — полный арсенал
- ⬜ F-Droid
