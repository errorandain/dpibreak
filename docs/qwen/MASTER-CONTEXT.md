## Что за проект
Локальный обход DPI-блокировок (YouTube, Discord, Telegram) на Android БЕЗ root.
Аналог zapret/GoodbyeDPI для телефона. Схема:
  VpnService (TUN) → hev-socks5-tunnel (tun2socks, C, git submodule)
  → локальный SOCKS5-движок byedpi (C, git submodule, через JNI)
  → исходящие сокеты через VpnService.protect().
Приложение НЕ VPN: ничего не отправляет на серверы, IP не меняет, не шифрует.

## Стек и версии
- Kotlin 2.0, Jetpack Compose (Material3), minSdk 24, targetSdk 35, JDK 17
- NDK + CMake 3.22 (нативная часть в app/src/main/cpp/)
- Версии зависимостей: gradle/libs.versions.toml (не дублировать в build-файлах)

## Правила кода
1. Идиоматичный Kotlin, без лишних зависимостей (сначала stdlib/androidx).
2. НЕ выдумывать API: если не уверен в сигнатуре (Compose, VpnService, NDK,
   JNI) — так и скажи и предложи проверить. Ошибка компиляции хуже отказа.
3. Блокирующие вызовы (JNI движка) — только в фоновых потоках/coroutines.
4. Сохраняй TODO(Задача N) маркеры в коде, если задача не решает их.
5. Каждый ответ: точный список созданных/изменённых файлов + полный код
   каждого файла (не диффы без контекста) + краткое объяснение.
6. Пиши код с комментариями на русском, идентификаторы — на английском.
7. После каждой задачи напомни мне: собрать (./gradlew assembleDebug),
   закоммитить. Не переходи к следующей задаче без моей команды.

## Ключевые инварианты архитектуры (см. docs/ARCHITECTURE.md)
- Исходящие сокеты движка/туннеля — ВСЕГДА через VpnService.protect(),
  иначе петля трафика. Также Builder.addDisallowedApplication(наш пакет).
- VPN-сервис всегда foreground (тип specialUse, Android 14+).
- Порядок запуска: startForeground → establish() → engine.start → bridge.start.
  Останов — строго в обратном порядке.
- Никакой телеметрии и сетевых запросов, кроме пользовательского трафика.
- Релизные ключи и local.properties никогда не коммитим.

## Советы по работе с Qwen

- **Одна задача = один диалог/коммит.** Не просите «сделай M2 целиком» — качество упадёт.
- После каждого ответа Qwen: соберите проект (`./gradlew assembleDebug`). Ошибки → верните их Qwen дословно («вот вывод компилятора, исправь»).
- Просите объяснять JNI-код — там ошибки самые дорогие.
- Если Qwen предлагает выдуманный API фейковой библиотеки — останавливайте: «проверь, что это реально существующий API».
- Крупные фичи (автоподбор стратегий) сначала обсуждайте текстом (план), потом код.
